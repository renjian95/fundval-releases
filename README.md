# 基智 App 发布页

本仓库**只存放编译好的安装包**，不含任何源码。

## 下载

进入 [Releases](https://github.com/renjian95/fundval-releases/releases) 下载最新的 `fundval-<版本>.apk`。

国内访问 GitHub 较慢时，在下载地址前加加速前缀即可：

```
https://gh-proxy.com/https://github.com/renjian95/fundval-releases/releases/download/<tag>/<文件>
```

## 安装

Android 8.0 及以上。首次安装需要在系统设置中允许「安装未知应用」。

已安装的 App 会在启动时自动检查更新，也可在「我的 → 检查更新」手动触发。
